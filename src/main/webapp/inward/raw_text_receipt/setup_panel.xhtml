1. Download the print agent below and unzip it to C:\hmis-print\.
  2. Share the dot-matrix printer: Printer properties, Sharing tab, tick Share this printer.
  3. Copy print-agent-config.example.json to print-agent-config.json and set PrinterPath to the printer's exact name and WatchFolder to C:\hmis-print.
  4. In Chrome, Settings, Downloads: set the location to C:\hmis-print and turn off Ask where to save each file.
  5. Put a shortcut to start-agent-hidden.vbs in the Startup folder (shell:startup), then run it once.
