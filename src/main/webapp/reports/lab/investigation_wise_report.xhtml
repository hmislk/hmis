function printInvestigationReport() { var table = window.PF ? PF('invesWiseTable') : null; if (table && table.paginator) { var total = table.paginator.cfg.rowCount; var shown = table.paginator.cfg.rows; // Only the current page exists in the DOM, so printing now // would drop the rest without saying so. if (total > shown) { var proceed = confirm( 'Only the ' + shown + ' rows on this page will be printed, ' + 'out of ' + total + '. Use the page-size dropdown below ' + 'the table to show them all, then print. ' + 'Print this page anyway?' ); if (!proceed) { return false; } } } window.print(); return false; }
